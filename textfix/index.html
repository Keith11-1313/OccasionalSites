    A little help
    Select text to transform only that part. With no selection, tools use the whole document. Line tools work best when you select complete lines.
    Use the star beside a tool to favorite it. Turn on recipe mode to queue several transformations.
    Ctrl / ⌘ + Z: undo
    Ctrl / ⌘ + Shift + Z: redo
    Ctrl / ⌘ + F: find
    Escape: leave expanded view
    Sentence and title case are mechanical conversions; review names and acronyms. Indentation tools preserve or normalize whitespace; they do not understand programming languages.
